# REST / WebSocket v1 首版契约

状态：BL-001 设计基线；关联 REQ-007～009 / NFR-003。TASK-001 补齐 OpenAPI、WS Schema、精确字段及错误样例。

## 通用规范

前缀 /api/v1，JSON UTF-8，UTC epoch 毫秒；Authorization: Bearer。首期 token 30 分钟，到期重新登录，不使用 URL 长期 token。

成功 {data,request_id}；错误 {error:{code,message},request_id}。分页 data={items,page,size,total}；page 从 1 开始，size 默认 20、上限 100。from 含、to 不含，默认最近 24 小时，最大 31 天；以时间和唯一 id 稳定排序。

401 未登录、403 无权、404 不存在（先做箱体授权）、400 参数非法、409 冲突、503 服务不可用。错误不返回 SQL/堆栈/凭据；登录失败使用统一文案。

## 路由

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /auth/login | username/password，返回 access_token、expires_at、role |
| GET | /me | 当前账号、角色、授权箱体摘要 |
| GET | /boxes | 授权箱体列表与独立状态 |
| GET | /boxes/{id}/latest | 字段级快照，按角色裁剪 |
| GET | /boxes/{id}/events | from/to/type/level/page/size；外卖用户只看结论和相关告警 |
| GET | /boxes/{id}/track | from/to/page/size；保留 MOCK |
| GET | /boxes/{id}/nodes | 允许诊断角色，无设备凭据 |
| POST | /boxes/{id}/commands | cmd、params、可选 target_node_id；202 返回 operation_id |
| GET | /boxes/{id}/commands/{operation_id} | 有控制权限者查询各节点结果及超时原因 |
| GET | /boxes/{id}/events/export | 物流操作者 CSV 导出 |
| POST | /ws-ticket | 登录后获取 30 秒一次性随机票据 |
| WS | /ws?ticket=... | 消费一次性票据连接 |

命令 POST 要求 Idempotency-Key（1～64 字节）；同用户/箱体/key 同请求返回原操作号，异请求 409。数据库持久记录至少 24 小时，超过保留期重用可生成新操作。服务端计算必需节点、目标能力和授权，不能信任客户端传入角色/能力。

操作状态 PENDING/RUNNING/SUCCEEDED/PARTIAL/FAILED/EXPIRED，含节点明细。全部必需节点实际完成才 SUCCEEDED。无控制权限者不能通过操作号读取明细。

## 快照、权限和实时推送

快照含 box_id、online_mask、connectivity、alarm、sentry、door 和按角色裁剪的 env/pose/loc。采样组含 value、valid、observed_at、received_at、stale、src、time_quality；未知 null。外卖用户完全省略 pose、node_diagnostics、evidence、哨兵操作明细，不能仅前端隐藏。

WS 握手检查 Origin、一次性 ticket、用户及 token 有效期；过期关闭重连。代理日志隐藏 ticket。
客户端 {v:1,type:"subscribe",box_ids:[...]}，逐项授权，任一无权则整次拒绝且不新增订阅；取消为 unsubscribe；30 秒 ping/pong。
服务器 {v:1,type,box_id,message_id,ts,data}，type=snapshot/box_event/alarm/command_status/node_status，data 复用 REST 权限投影。

WS 不承诺可靠重放；重连后 REST 重取快照与上次时间之后事件，用 id 去重，显示断线/同步状态。位置始终保留 MOCK。

## 导出与审计

导出按相同角色、箱体、时间范围过滤；CSV UTF-8，正确转义引号换行；文本以 =/+/-/@ 开头时做公式注入防护。记录控制、导出、登录失败、拒绝访问的操作者、范围、结果及 request_id，不记录密码、JWT 或设备密钥。
