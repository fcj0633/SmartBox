# TASK-011资产接口增量

这是CR-006演示切片的后端资产接口，独立于冻结v1的11个设备HTTP操作。本目录不改写冻结契约，也不授予设备控制权限。

- [OpenAPI](openapi.yaml)：四个JWT接口、请求、成功和错误响应。
- [结构定义](responses.schema.json)：资产DTO白名单；没有传感器快照或账号凭据。
- [正反样例](fixtures.json)：结构检查输入，不是运行证据。
- [只读检查工具](../../../tools/check_assets_contracts.py)：本地引用、接口覆盖、认证声明及样例。

所有接口使用现有`data/request_id`成功结构，失败使用`error/request_id`。分配输入只接受正整数`rider_user_id`，身份及企业由服务器确定。重复分配同一骑手200并保留原时间，其他骑手占用409 `BOX_ALREADY_ASSIGNED`；重复收回200、`assigned=false`。未认证401，非本企业管理员或个人箱体企业操作403，无效目标400。数据库不可用503。

新分配只影响新资产列表。原`user_box_access`、设备查询和控制不自动变化，因此“收回分配”不能表述为“已撤销全部设备访问”。当前无运输任务表；TASK-012需在同一锁定路径增加ACTIVE期间禁止普通收回。个人资产和企业资产查询不返回伪造设备状态。
