## 连接与身份

MQTT 3.1.1；clientId=node_id；keepalive=60 秒；clean session=true。重连必须重新订阅，再上报当前状态和补传。遥测 QoS0，事件/心跳/下行/回执 QoS1；均 retain=false。LWT QoS1、retain=false，含 node_id、boot_id、online=false；后端按当前代次匹配，忽略旧代次遗嘱。

重连采用 1/2/4/8/16/30 秒上限加 0～20% 抖动，持续重试，成功后复位。单次 I/O 有截止时间。单任务持有 MQTT 客户端，回调仅有界拷贝入队。

身份预配置，box_id/node_id 为 1～48 字节 ASCII，允许字母、数字、横线、下划线，禁止 /、+、#。生产 TLS，开发使用独立账号 ACL；不采用需要额外 Broker 插件但尚未实现的动态 HMAC 认证。

| 能力 | 位 |
|---|---|
| 环境/补光/风扇 | 0x01 / 0x02 / 0x04 |
| 姿态/本地灯/定位/哨兵 | 0x08 / 0x10 / 0x20 / 0x40 |

ENV=0x47=71；POSE=0x78=120。目标能力要求全部满足。

## Topic 与权限

完整前缀：box/{box_id}/{node_id}/。

| 方向 | 后缀 | QoS | 含义 |
|---|---|---|---|
| 上行 | property | 0 | 最新遥测，默认 1 秒 |
| 上行 | heartbeat | 1 | 30 秒心跳及当前状态 |
| 上行 | event | 1 | 事件或有界补传批次 |
| 上行 | command_ack | 1 | 命令结果 |
| 上行 | availability | 1 | 上线状态/LWT |
| 下行 | cmd | 1 | 节点命令 |
| 下行 | event_ack | 1 | 后端持久化后的业务确认 |
| 下行 | box_state | 1 | 融合门状态等本地所需信息 |

节点仅能发布自己的上行主题、订阅自己的下行主题，禁止全方向 /# 发布权限。后端账号独立授权。topic 与 payload 身份不一致、未注册或箱体归属错误均拒绝。

## 时间与标识

业务上行包含 v、box_id、node_id、boot_id、ts、ts_src、uptime_ms、time_uncertainty_ms；property/heartbeat 另含 role/caps，与注册值一致。

- v=1；boot_id 为节点持久化递增 uint32 代次，不得复用。重启或序号耗尽前持久化切换；存储失败停止产生声称唯一的新事件并报告。
- event_seq、property_seq 为分开计数的 uint32，从 1 开始；事件键为 node_id+boot_id+event_seq，不使用 MQTT 包号去重。
- ts 为 UTC epoch 毫秒；未校时为 null，ts_src=UNSYNCED，time_uncertainty_ms=null；已校时为 SNTP。不能把 uptime 当 UTC。
- uptime_ms 为本代次 uint64 单调时间；后端 received_at 使用服务器 UTC 毫秒。
- 历史事件保留原始时间与质量；后端可用同 boot 同步锚点估时，但保存原值/估计值和质量，不伪装为原始精确 UTC。
- replayed=true 的事件不推进最新快照。融合高置信需双源不确定度各不超过 500ms。

## 遥测、心跳与容量

property 只包含角色支持字段；无效值为 null，禁止 NaN/Infinity。env 为 temp_c、humi_pct、lux、valid、light_on、fan_on；pose 为 acc_g、tilt_deg、state、valid；loc 为 lat、lon、valid、src=MOCK。

心跳包含 role/caps、sentry 状态/revision、传感器质量、pending_events、overflow_total、lost_ranges 和 storage。字段级 observed_at 来源于设备时间与质量，received_at 由后端生成。

JSON payload 上限 1536 字节 UTF-8，完整 MQTT 帧上限 2048 字节，topic 上限 128 字节。每批最多 4 个事件且必须满足字节上限，超限拆批。不能沿用历史实验 192 字节拷贝上限。缓冲和队列纳入 RAM 实测。

## 事件与持久化确认

event 外层有身份；events 每项含 event_seq、ts、ts_src、uptime_ms、time_uncertainty_ms、type、src、level、data、replayed。不使用外层发送时间代替每项发生时间；不同 boot_id 不得混批。

类型：ENV_HIGH/ENV_LOW/ENV_RECOVERED、POSE_CHANGED、IMPACT、DOOR_EVIDENCE、SENTRY_INTRUSION、GEOFENCE_EXIT/GEOFENCE_ENTER、STORAGE_OVERFLOW、DEVICE_FAULT。level 为 INFO/WARNING/CRITICAL；data 采用具名有单位字段，弃用 v1/v2。门证据含 action=OPEN/CLOSE、tilt_deg 或 lux、actuator_excluded。

顺序：本地持久化 → 发布 → 后端校验 → 原始事件与派生处理 outbox 同事务提交 → event_ack → 可恢复的幂等融合/告警。只有数据库事务提交后才确认。

event_ack 含 v、box_id、node_id、boot_id、event_seqs、result=stored、ts。event_seqs 为精确已保存序号列表，不是最大序号以前全部确认。重复且内容一致返回 stored；同键异内容拒绝并审计，不覆盖原记录。

设备收到合法匹配身份的业务确认才清理；PUBACK 不证明落库。确认丢失可重发；数据库回滚不发 stored。非法报文不进入无限重试解析。

本地至少保存 64 条未确认事件；满后覆盖最旧并持久记录 overflow_total 和损失区间，通过心跳持续暴露，不依赖向已满队列再塞事件才能发现溢出。

## 命令与回执

cmd 含 v、request_id（1～64 字节）、operation_id、box_id、node_id、cmd、target_caps、issued_at、expires_at、params。时间 UTC 毫秒；QoS1、retain=false，接收 retained=true 命令一律拒绝。

| 命令 | target_caps | params |
|---|---|---|
| sentry | 64 | on 布尔、duration_s 0～86400（0 无自动到期）、sentry_revision 正整数 |
| profile | 1 | profile_id、温湿度上下限、回差；必须形成有效恢复区间 |
| gps_mode | 32 | mode=FIXED/ROUTE/WALK、seed |
| output | 2/4/16 | kind=light/fan/indicator、on 布尔、duration_s 1～30；按 kind 精确校验位 |
| calibrate | 8 | params 为空对象，执行静置校准 |

有效期初始 15 秒；设备无可靠 UTC 返回 time_unsynced，不执行远程动作。本地监控不受影响；后端不向已知未校时节点发送控制。

command_ack 含 v、身份、boot_id、request_id、operation_id、result、code、actual_state 及完整时间字段。result=ok/ignored/busy/error/expired；code 区分 completed、unsupported_caps、invalid_params、time_unsynced、stale_revision、storage_error。

ok 表示实际动作完成。最近至少 32 个 request_id 缓存结果；同号不同请求报 conflicting_request。重启后缓存可丢失，但有效期、幂等设定命令和持久化 sentry_revision 阻止过期/旧布防覆盖。

箱体布防按必需节点逐个下发，共用 operation_id，各有 request_id。revision 单调递增；3 秒缓冲后实际 ARMED 才完成。10 秒超时，全部完成才 ARMED，部分失败显示 PARTIAL，不假装自动回滚。撤防也需逐节点结果。

box_state 含 v、身份、door_state、conclusion_id、historical=false、ts。只处理未过期新结论；OPEN 触发 ENV 30 秒抑制窗口。历史补传不发送当前状态；未校时不推断窗口。
