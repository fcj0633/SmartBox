# SmartBox 三套视觉方向预览

本目录是独立于生产前端的设计探索原型，不接入当前 API、Pinia 会话、权限或控制命令，不改动 `frontend/src` 中的产品代码。运行时只依赖仓库现有 Vue/Vite 安装，不新增依赖。

## 启动

在仓库根目录执行：

```powershell
frontend/node_modules/.bin/vite --config frontend/design-exploration/vite.config.ts
```

浏览器打开 `http://127.0.0.1:5186`，顶部切换三套方向，左侧切换每套方向的五个代表页面。也可用查询参数直达页面，例如：

```text
http://127.0.0.1:5186/?direction=command&page=dashboard
http://127.0.0.1:5186/?direction=industrial&page=alarms
http://127.0.0.1:5186/?direction=route&page=operations
```

## 方向

| 方向 | 色彩与组件 | 主要特征 | 代表页面 |
|---|---|---|
| 运营指挥台 | 深海军蓝侧栏、白色工作区、青绿色在线态、暖橙告警；密集 KPI、轻表格分隔、抽屉详情 | 总览、资产表格、环境与节点详情、告警队列、设备工作区 |
| 工业资产工作区 | 石墨绿侧栏、雾灰工作区、苔绿健康态；资产树、矩阵状态、参数趋势与规则事件 | 左侧资产层级、设备健康矩阵、遥测趋势、规则事件、节点指标 |
| 物流地图控制台 | 海军蓝导航、浅地图底、琥珀路线与事件态；地图主视图、任务列表、联动位置面板 | 运输态势总览、路线批次、可选地图标记、资产位置详情 |

三套统一使用 **Manrope + Noto Sans SC**，正文约 9–12px（紧凑运营台）并保留高对比标题、分组间距及颜色以外的状态文字。生产落地时应按真实页面密度再校准字体，不直接复用截图的缩放比例。

## 状态标记与数据边界

- 本预览所有指标、环境数值、事件、告警、轨迹、时刻和用户身份均为 **Demo / Mock Data**。
- 现有能力基础：登录、授权箱体列表、箱体快照与质量状态、按角色裁剪的箱体详情、现有控制提交流程。
- 规划扩展：运营 Dashboard、完整告警生命周期、GPS 地图/轨迹/围栏、资产创建与批量管理、设备管理、画像/规则管理、通知中心及审计。
- 原型中的门状态明确为 `UNKNOWN`；定位展示为 Mock；设备电量与通信信号未接入时显示 `—`，不编造数据。
- “确认告警”等按钮只改变当前原型的演示提示，不写入服务端，不代表真实权限、规则或操作已经生效。

## 交互

- 顶部切换方向，左侧切换五个页面；页面选择保持在 URL 查询参数中。
- 资产表支持文本搜索、在线/离线筛选和详情跳转。
- 箱体详情支持分区 Tab；地图与设备视图支持选择箱体并联动位置/详情。
- 告警表行打开详情抽屉，可查看来源、时间线和演示备注；Esc 可关闭抽屉/通知菜单。
- 通知、筛选、确认和控制入口以 toast 明确标出模拟或规划状态。
