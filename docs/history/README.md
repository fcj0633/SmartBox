## 使用原则

- `TASK-000`、`REL-000` 等冻结文件保留历史字节，内部可能仍有旧目录/测试链接；以本索引和当前导航为准，不修改冻结字节。

- 需要理解“为什么当时这样做”时读；实施新功能时以当前需求、设计、任务为准。
- 不修改历史结论来迎合当前实现；当前变化记录在[项目演进](../project/项目演进.md)。
- 历史测试用例/报告不再单独维护；验证摘要保留在对应 TASK 和当前进度中。
