## 背景和目标

演示正常、倾斜、侧翻、倒置与冲击，不将动作模拟解释为真实安装后的准确率。

## 业务流程

输入采集或授权请求 → 校验身份和数据质量 → 业务判断/执行 → 记录事件或结果 → 按权限展示。采集、持久化及网络相互解耦。

## 功能规则

1. 初始姿态采样 50Hz；姿态展示最多 1Hz。需在 P2 记录实际周期与资源占用后确认采样参数。
2. 合盖模拟姿态静置 3 秒后校准基准重力方向；只有有效、近静止样本参与。校准失败显示未校准，不输出可信倾角。
3. 量程与驱动配置一致后换算 g；现有 SC2 驱动配置需在 P2 确认，禁止仅凭文档常数盲除。
4. 相对基准倾角区间：[0,10)正常、[10,45)倾斜、[45,90)侧翻、[90,180]倒置。持续 200ms 确认状态切换；边界回差 2°，初始状态直接按区间确定。
5. 冲击候选为 abs(|a|-1g)>0.5g，记录峰值、发生时间和样本质量；相邻 1 秒候选合并一次冲击事件。它是冲击演示，不能声称已区分真实跌落与其他运动。
6. 加速度近零、无效或强动态期间不计算有意义的倾角；保留冲击候选，不用除零或无效 arccos 结果更新姿态。

## 异常与降级

无效输入不冒充正常数据；错误保留诊断和时间质量。网络离线保持本地能力，网页标注过期和降级。涉及跨端执行的成功必须以实际回执为准。

## 验收标准

水平、各级边界与倒置分类；零向量和动态输入不会产生非法浮点结果；快速脉冲输入被捕获且合并；板端实际采样另验。

测试预期和实际结果分开；关联用例见 [测试用例目录](../../testing/cases/README.md)。
