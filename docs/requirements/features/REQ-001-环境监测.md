## 背景和目标

环境变化可观测，按可配置物品画像判断异常；界面区分正常、异常、无效和过期数据。

## 业务流程

输入采集或授权请求 → 校验身份和数据质量 → 业务判断/执行 → 记录事件或结果 → 按权限展示。采集、持久化及网络相互解耦。

## 功能规则

1. ENV 每 1 秒采集温度、湿度、光照，记录有效标记；读取失败不填零伪装正常。
2. 画像阈值可配置。首轮 demo 画像仅用于演示：温度 2～8℃、湿度 30～85%RH；这些数值不代表实际货物保存建议。更改画像产生审计记录。
3. 连续 3 个有效帧同向越界产生一次异常进入事件，持续异常不每秒重复。无效帧中断连续计数。
4. 温度回差 1℃、湿度回差 3%RH；恢复也要求 3 个连续有效帧。例如温度高于 8℃进入判定，降至不高于 7℃才恢复。
5. 光照为观测与门证据输入；除专门光照异常外不使用温湿度画像规则。
6. 模拟开门确认后 30 秒内不新增温湿度超限事件；保留采集和已有告警，窗口结束重新计数。断网未收到融合结论时不假装已触发该窗口。
7. 补光开关状态随数据记录，补光及切换后 2 秒不用于光照门证据。

## 异常与降级

无效输入不冒充正常数据；错误保留诊断和时间质量。网络离线保持本地能力，网页标注过期和降级。涉及跨端执行的成功必须以实际回执为准。

## 验收标准

断开传感器显示无效；单帧尖峰不告警；连续 3 帧进入、回差区不抖动、3 帧恢复；补光不触发开门。

测试预期和实际结果分开；关联用例见 [测试用例目录](../../testing/cases/README.md)。
