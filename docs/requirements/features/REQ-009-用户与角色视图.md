## 背景和目标

按箱体授权及业务角色展示数据，REST、实时推送和导出使用相同服务端授权。

## 业务流程

输入采集或授权请求 → 校验身份和数据质量 → 业务判断/执行 → 记录事件或结果 → 按权限展示。采集、持久化及网络相互解耦。

## 功能规则

1. 登录颁发短期访问令牌；用户必须同时满足角色权限与 box 授权。默认拒绝，不靠前端隐藏保障权限。
2. 物流寄收件人可读授权箱体全量业务信息；物流操作者另可布撤防和导出。设备凭据不属于“全量业务信息”。
3. 外卖用户可看环境、MOCK 定位、融合开合结论及相关告警，不看原始倾角/光照证据，不执行控制，不看设备诊断。
4. 骑手可看授权箱体业务数据、开合证据和哨兵，可布撤防；配置画像、输出、校准和 GPS 模式仅物流操作者可用。
5. 查询、WS 订阅和导出均做箱体范围过滤；用户不能通过改 URL、请求体或订阅消息绕过。
6. 网页包含箱体列表、详情、环境/姿态/定位卡片、事件告警、命令状态；按权限显示。P1 先实现最小列表、详情及命令状态。
7. 导出为授权事件 CSV，防公式注入，记录操作者和范围；定位及设备明细按相同字段权限裁剪。

## 异常与降级

无效输入不冒充正常数据；错误保留诊断和时间质量。网络离线保持本地能力，网页标注过期和降级。涉及跨端执行的成功必须以实际回执为准。

## 验收标准

各角色允许/拒绝矩阵通过；跨箱体查询、WS 订阅、命令及导出均拒绝；外卖用户可见融合结论且无证据字段泄漏。
