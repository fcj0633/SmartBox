# MOD-06 用户与权限管理

基线：BL-002；版本：1.0；组织重构已授权，迁移验收见CR-002。实现及SmartBox板端结果未验证。

## 背景、目标与职责边界

为身份、角色、箱体范围、字段、控制和导出提供一致授权及审计。

适用角色：物流寄收件人、物流操作者、外卖用户、骑手及后端授权服务。

不替聚合模块组织所有业务数据，不新增自助注册或用户管理后台。

本模块是所属业务及子需求的权威需求来源；系统总纲负责整体协作，契约负责协议细节。功能重组不代表六个微服务，不改变固件分层和现有后端。

## 场景与总体流程

1. 受控账号登录后建立有期限身份，校验角色与箱体范围。
2. 对查询、实时订阅、操作号、控制和导出采用相同权限规则。
3. 服务端裁剪字段后交页面，禁止以隐藏按钮代替拒绝访问。
4. 操作及拒绝保留脱敏审计；令牌失效重认证，不通过URL或日志泄漏秘密。

前置条件：受控身份、归属、权限及适用配置已准备；官方IA1/SC2例程据用户反馈可编译、烧录、运行，但SmartBox集成仍待验证。触发为周期输入、授权操作或恢复事件，正常结果与降级结果都应可解释。

## 典型场景与完整分支

| 场景 | 前置/触发 | 正常流程 | 分支及异常 | 结束与结果 |
|---|---|---|---|---|
| 外卖用户查看 | 已登录并有box范围 | 裁剪环境、MOCK、融合结论与相关告警 | 改URL/订阅不泄原始证据 | 最小可用业务信息 |
| 骑手和物流控制 | 已有角色及箱体授权 | 骑手布撤防，操作者执行既有配置 | 无权请求不得传设备，操作号查询受控 | 权限一致的控制闭环 |
| 实时与导出 | 身份有效且出口可用 | REST/WS/CSV同范围同字段规则并审计 | 令牌过期、票据复用、跨box均拒绝 | 脱敏且一致的访问结果 |

**处理目标与正常流程：** 验证身份和会话有效期。前置条件满足后处理有效输入，形成访问身份或统一失败；若输入质量或授权不满足，进入明确拒绝/降级分支。

**现行规则：**

**权限与质量：** 角色范围及NFR见模块统一约束；具体业务授权与数据质量要求按本条规则和上下游执行。

**验收标准：** 30分钟token及30秒一次性票据等契约约束保留，失效/复用拒绝。 对照关联TC保存真实输入、结果与证据；软件/模拟通过不得替代板端验证。

**待决：** 本条不新增业务决定；若测试暴露规则缺口，进入CR流程，不自行改变阈值。
