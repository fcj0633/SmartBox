# MOD-07 运输任务与过程管理

> 候选 BL-003 业务模块：编号已登记，**尚未批准或实施**。依据 [CR-006](../../management/changes/CR-006-多角色物流箱与运输任务平台.md) 与 [V1.1 多角色需求](../SmartBox多角色物流箱管理平台需求变更说明.md)。

## 目标与职责边界

管理一次运输的创建、物品、READY/ACTIVE/COMPLETED、同箱排他、责任快照、可信时间归属及任务级历史。箱体所有权与分配由 MOD-05 承担，企业和访客访问授权由 MOD-06 承担；原始设备采样、MQTT、规则、告警及可靠事件分别保留现有职责。

运输状态与设备在线、环境评估、样本新鲜度是独立概念。V1 不实现进行中换箱/取消、复杂派单、签收、支付或真实 GPS。详细事务约束见 [数据设计](../../design/backend/CR-006-企业箱体与运输任务数据设计.md)。
