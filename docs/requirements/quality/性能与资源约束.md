# NFR-001 性能与资源约束

状态：已确认；任务 TASK-007、008、009、010；用例 TC-010。

| 指标 | 验收口径 |
|---|---|
| 环境周期 | 每 1 秒采集；记录实际间隔与无效读取 |
| 姿态周期 | 初始 50Hz，P2 以日志确认；必要修订需 CR |
| 心跳 | 默认 30 秒，离线阈值 90 秒 |
| 普通事件在线链路 | 从本地规则确认事件到网页显示 ≤2 秒；不含规则去抖时间 |
| 哨兵本地快速响应 | 从快速异常判定成立到灯/风扇输出 ≤1 秒，不依赖云端 |
| 门融合在线时延 | 从后端收到首份候选到发布结论 ≤3 秒；证据累计 1.5 秒和网络传送另计 |
| 节点资源 | 应用增量 RAM 峰值 <60KB（排除 SDK/Wi-Fi/TLS 基线），Flash 增量 <200KB |
| 连续性 | 24 小时记录丢帧、重启与资源曲线；见 NFR-002 |

在正常局域网、双节点校时有效条件下采集至少 100 次在线事件，保存最大值及 P95；最大值超过指标即记录失败，不能仅以平均值通过。实际资源以 SDK 基线与应用构建映射及运行峰值差值说明，不能只累加结构体大小。P1 模拟链路结果与 P2/P4 板端指标分开记录。
