# NFR-003 安全与可维护性

状态：已确认；任务 TASK-001、003、004、005、006、010；用例 TC-009、TC-012。

- 局域网调试允许 1883，仅绑定受控网卡并限制来源；使用每节点独立凭据及 ACL，不允许匿名共享发布。生产部署要求 TLS 8883，本期不宣称生产验证。
- 节点只发布自己上行 topic、订阅自己下行 topic；后端账号独立拥有聚合需要的权限。声明的 node_id 必须与连接授权范围及 topic 一致。
- 应用密码只存安全散列；JWT 有过期时间，REST/WS/导出均执行箱体和角色授权。长效 token 不放 URL、日志或 Git。
- HTTP 请求校验字段与长度，统一错误号和 request_id；不回传异常堆栈、密码或 SQL。
- 模拟坐标及用户数据仅对授权用户返回；日志脱敏，原始证据归档前检查隐私。
- Flyway 管理结构迁移，禁止开发启动时自动破坏已有数据库；依赖精确锁定并记录兼容矩阵。
- 固件同一套代码按角色构建；报文含版本；旧 SDK 接口必须通过实际链接确认。协议版本不支持时拒绝，不猜测降级。
- REQ—设计—TASK—TC—发布关联可检查；模拟、软件和硬件证据分开保存。
