# 术语表

| 术语 | 定义 |
|---|---|
| box_id | 逻辑物理箱体身份，多节点共同归属 |
| node_id | 全局唯一设备身份及 MQTT clientId |
| ENV / POSE | IA1 环境节点 / SC2 姿态节点 |
| caps | 位掩码能力集合，ENV=71、POSE=120 |
| boot_id | 节点持久化运行代次；node 内不重复 |
| event_seq | 运行代次内 uint32 事件序号，不等于 MQTT 包号 |
| property_seq | 运行代次内遥测序号，与 event_seq 分开 |
| PUBACK | MQTT QoS1 的传输确认，不证明后端落库 |
| event_ack | 后端事件事务持久化后的业务确认 |
| command_ack | 节点命令执行结果 |
| 门证据 | 光照或倾角提供的模拟开合候选 |
| 箱体结论 | 后端按证据时间和质量融合的结果 |
| stale | 字段已过期；不同于节点离线 |
| MOCK | 伪定位来源，必须显式展示 |
| BL / ITER / REL | 需求基线 / 开发迭代 / 发布记录 |
| 软件完成，待板端验证 | 软件检查通过但未取得实际硬件证据 |
