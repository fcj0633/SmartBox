# 产品范围与场景

状态：已确认；基线 BL-002。

## 场景

物流场景：寄收件人与物流方查看授权箱体环境、姿态、模拟轨迹和异常，物流操作者可调整画像与布撤防。
外卖场景：用户查看环境、模拟位置、融合后的开合结论与相关告警；骑手查看证据、布撤防并保存过程记录。

## 范围

一个箱体配置 ENV、POSE 各一块，可扩展多个逻辑箱体。ENV 搭载 IA1，POSE 搭载 SC2 与 GPS Mock。云端首先由局域网 Windows 后端和 Broker 承担，网页手机/电脑均可访问。

本期不制作箱体；手动改变光照和转动 SC2 作为模拟开合动作，不承诺识别实际门、整箱转动与掀盖的准确率。无真实 GPS、蜂鸣器或振动执行器；灯和风扇用于提示。不是实际冷链控制或安全保障装置。
