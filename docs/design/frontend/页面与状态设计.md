# 页面与状态设计

关联 REQ-M05-001、REQ-M05-002、REQ-M05-003、REQ-M05-004、REQ-M05-005、REQ-M03-004、009；TASK-006、008、010。

P1：登录、授权箱体列表、详情和命令状态；后续补事件筛选、轨迹、告警和导出。卡片显示数据时间、节点在线、字段过期和 MOCK。

按角色展示入口，REST/WS 服务端裁剪真正限制数据。外卖用户不出现原始证据与控制操作。页面独立支持 loading/empty/error/ready，不用“正常”代替未加载。

REST 初始化后 WS 更新；断线标注最后更新时间，重连 REST 重同步，事件 id 去重。token 仅内存保存，刷新重新登录，不写 URL 或日志。

命令显示 PENDING 与逐节点结果；PARTIAL/超时不能显示已全部布防。地图接入前可先以坐标和明确 MOCK 轨迹展示；第三方地图需另行核对坐标体系，不隐式转换。
