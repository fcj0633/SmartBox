# 页面与状态设计

需求引用以文末业务映射为准；TASK-006、008、010按各自交付切片实施。节点通信显示同时关联REQ-M03-004。

P1：中文浅色电脑端，登录、授权箱体列表、详情、实时状态、授权控制和命令结果；主要尺寸1440×900，检查1280×720，不要求手机布局。完整历史筛选、轨迹和CSV页面由TASK-010完善；业务告警/融合由后续适用任务接入。详细页面、接口、工程组织、S1～S7和F01～F14集中维护在[TASK-006](../../development/tasks/TASK-006-网页与首轮闭环验收.md)，本文不重复维护细节。

按角色展示入口，REST/WS 服务端裁剪真正限制数据。外卖用户不出现原始证据与控制操作。页面独立支持 loading/empty/error/ready，不用“正常”代替未加载。

REST初始化后WS更新；连接/恢复后再REST重同步，切箱及旧响应隔离见任务6。断线标注最后同步时间，业务ID去重，不用推送message_id代替事件ID。token仅内存保存，刷新重新登录，不写URL、持久存储或日志。

命令显示 PENDING 与逐节点结果；PARTIAL/超时不能显示已全部布防。地图接入前可先以坐标和明确 MOCK 轨迹展示；第三方地图需另行核对坐标体系，不隐式转换。
