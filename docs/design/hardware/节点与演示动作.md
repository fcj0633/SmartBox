# 节点与演示动作

关联 REQ-001～005、ASM-001。硬件正常为假设，本文不是实测。

| 节点 | 板件 | 现有 SDK 接口 | 注意 |
|---|---|---|---|
| ENV | Nano + IA1 | I2C1 GPIO0/1，补光 GPIO14，风扇 GPIO8 | 补光污染需排除，默认输出关闭 |
| POSE | Nano + SC2 | MPU6050，D1 GPIO7，D2 GPIO8 | 与 ENV 独立板，不冲突 |
| GPS | POSE Mock HAL | 无新增外设 | 不声称真实位置 |

演示：静置校准 → 低光照 → 同时照亮 IA1 并转动 SC2 模拟开门 → 恢复模拟关门 → 单源动作展示降级 → 布防后快速异常展示提示。

P2 记录板号、串口、量程、读数、输出及固件校验值。冲击先用注入和安全手动动作，不摔裸板。双板可靠供电，引脚复用依据实际驱动和板卡版本复核。
