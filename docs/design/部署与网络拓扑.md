# 部署与网络拓扑

## 当前拓扑

```text
开发板 / 模拟器
        ↓ MQTT over TLS 8883
远程 EMQX Cloud Broker
        ↓
本机 Spring Boot
        ↓
MySQL
        ↓ REST / WebSocket
浏览器 / Vite
```

当前只支持远程 Broker：

```text
z789ffe0.ala.cn-hangzhou.emqxsl.cn:8883
```

本地配置位于：

```text
deploy/demo/mqtt.cloud.json
deploy/demo/emqxsl-ca.crt
```

后端启动默认读取并连接；配置缺失时才进入模拟模式。

- 板端和电脑无需同一 LAN，但都必须能访问远程 Broker；
- 后端和网页仍在本机回环；
- 浏览器不持有 MQTT 凭据；
- 不提供本地 Mosquitto、旧 LAN Broker 或 `local` 模式。

## 服务

| 服务 | 当前配置 |
|---|---|
| Spring Boot | 8080，本机回环 |
| Vite | 5173，本机回环，代理 `/api` 和 `/ws` |
| MySQL | 本机 8.0 |
| MQTT | 远程 TLS 8883 |

## 边界

- 本仓库不提供远程 Broker 的创建、账号/ACL 或证书轮换；
- 真实板固件、SDK 编译和烧录不在 main；
- 远程凭据和 CA 由本地忽略配置提供，不提交；
- 没有本地 Broker 回退路径。
