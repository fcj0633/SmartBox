# 后端模块与数据模型

关联 REQ-006～009；TASK-003、005、008～010。

Java 21 / Spring Boot / MyBatis / Flyway / MySQL 8。单个 Maven 应用按 auth、box、node、telemetry、event、fusion、alarm、command、ingestion 组织，每模块内实现接口、应用服务、规则及持久层。统一参数校验、错误、审计和授权。

| 逻辑表 | 核心数据和约束 |
|---|---|
| users / roles / user_box_access | 密码散列、角色、箱体范围 |
| boxes | box_id 唯一、画像、必需节点、sentry_revision |
| nodes | node_id 唯一、归属、role/caps、当前 boot、last_seen |
| telemetry / node_latest | 历史和最新分开，保留时间/质量/来源 |
| events | node_id+boot_id+event_seq 唯一、原始载荷、replayed |
| processing_outbox | 可恢复派生任务、重试次数和状态 |
| box_events / event_evidence | 结论、证据关联、派生幂等键 |
| alarms | 级别、来源、开始/恢复 |
| command_operations / node_commands | 操作、节点请求、revision、实际状态与超时 |
| idempotency_records / audit_logs | 用户请求键和散列、范围、结果 |

TASK-003 输出物理字段、外键、索引和迁移，并同步 ER 图。索引至少覆盖箱体时间查询、事件唯一键与授权连接。

事件与 outbox 同事务提交，提交后 event_ack；派生结果幂等并可恢复。历史不覆盖最新快照。项目数据库与账号独立，不重用其他项目表。开发种子仅受控 profile 执行，不生成通用生产弱口令。
