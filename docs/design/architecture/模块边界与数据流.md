| 模块 | 输入 | 输出与边界 |
|---|---|---|
| 固件 HAL | I2C、GPIO、Mock | 有单位及有效位的样本，不做云端融合 |
| 固件规则 | 样本、画像、布防 | 事件和本地输出，不阻塞网络 |
| 事件服务 | 事件、业务确认 | 持久化/补传，不将 PUBACK 当落库 |
| 网络服务 | 队列、配置、命令 | 单 MQTT 所有者，回调只入队 |
| 后端接入 | 已授权 MQTT | 校验 topic、身份、版本、容量 |
| 事件模块 | 合法事件 | 唯一键事务、outbox、提交后确认 |
| 融合/告警 | outbox、时间质量 | 幂等结论，历史不冒充实时 |
| 命令模块 | 授权操作 | 请求幂等、逐节点执行状态及审计 |
| 查询投影 | 用户、角色、授权箱体 | REST/WS/CSV 统一裁剪 |
| Vue | 授权响应 | 页面状态和操作请求，不替代后端鉴权 |

遥测：采集 → MQTT → 接入 → telemetry/latest → 授权推送。
事件：规则 → 本地持久 → MQTT → 事件与 outbox 事务 → event_ack → 幂等融合/告警 → 推送。
命令：网页 → 授权/幂等落库 → MQTT → 节点执行 → command_ack → 操作状态 → 网页。

后端故障不删除设备未确认事件，网页断线后 REST 重同步，本地能力不依赖网络。
