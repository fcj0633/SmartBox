# 部署与网络拓扑

默认 Windows 运行服务端、前端、MySQL 和项目 Mosquitto；Ubuntu 交叉编译。

| 服务 | 初始配置 | 现状 |
|---|---|---|
| Spring Boot | 8080，默认回环 | 待开发 |
| Vite | 5173，回环；代理 /api 和 /ws | 待开发 |
| MySQL | 现有本机实例，权限在 TASK-003 验证 | 未建项目库 |
| MQTT | 1883，绑定板端可达受控网卡 | 服务停止；TASK-004 配置 |
| MQTT TLS | 8883 | 本期不宣称生产验收 |

手机演示需要显式开放前后端 LAN 地址。板端与 Windows 在可互访的 2.4GHz 网络；热点排除客户端隔离。虚拟网卡不是板端应填的 Broker 地址；地址会变，禁止照抄历史 IP。

Z: 映射 Linux 根目录，SDK 在 /home/bearpi/project/bearpi-hm_nano；映射仅能访问文件。首次手工在 Ubuntu 终端编译，SSH 自动执行不作为门槛。

本地凭据通过环境变量/忽略的 local 文件提供；不改既有服务全局设置，不清空其他数据库。
