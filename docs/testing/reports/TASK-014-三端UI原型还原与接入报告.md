# 三端 UI 原型还原与工程接入实施报告（TASK-014）

日期：2026-11-24。执行者：Codex；用户独立负责最终验收。源码基线从 `1b9b0bb` 快进同步到 `76a2296` 后实施。关联 [TASK-014](../../development/tasks/TASK-014-三端UI原型还原与工程接入.md)、[TC-015](../cases/TC-015-任务历史访客安全与页面.md)。本轮完成 DEMO 三端 UI 还原，不代表实板、可靠补传或生产安全验收。

## 1. 实际交付

- 企业正式页采用已选 route 方向：深蓝侧栏、顶部工作区、地图与任务双栏，保留概览/资产/运输分区、搜索、任务联动、真实分配/收回与任务详情。底图形态取自原型，移除真实资产假位置、城市与假路线；明确“示意地图，无真实 GPS”。任务计数限定最近 50 项返回范围。
- 骑手工作台恢复当前运输主区、内嵌环境、我的箱体侧栏与手机四导航；无任务/无箱体有明确入口。增加受 COURIER 保护的箱体、历史、我的、准备路由；资产详情仅显示授权列表与本人任务能够证明的信息，不借资产资格扩大旧设备权限。
- 准备流程为选箱→绑定→核对，创建成功后使用服务端 task_id 的任务地址。草稿可回填、返回和重新登录后恢复；编辑内容不被轮询覆盖。返回第一步保留原草稿，更换箱体必须明确确认另建。创建结果不明不自动重试；开始检查离线并显式确认风险；结束二次确认。分享为次级区域，原文仅当前组件内存显示，可隐藏，不进 URL 或日志。
- 普通用户以独立验证入口进入；验证后运输身份→环境主区→环境/事件入口→进度，手机没有企业/骑手导航。保留原专用 token、generation、SerialRead、10 秒刷新、到期计时和退出清理；错误/失效不保留任务数据，二级页仅使用当前授权返回的 samples/events。
- 共用环境、时间线、真实采样图、事件和任务概览；没有导入原型内存 Store、固定任务或验证码。UNKNOWN 不变正常；无效读数隐藏，零读数保留，缺口断开，无样本/单点不补造序列；已结束任务不使用箱体后续快照。
- 样式从原型迁移并挂在业务根类下，企业仅迁移 route 对应结构。原型 Icon 复制为生产本地图标，部署不依赖原型业务代码；无新增依赖。旧业务 CSS 保留文件但不再由新布局导入，不污染旧设备页。

入口仍是 `/enterprise`、`/rider`、`/track`；新增 `/rider/boxes`、`/rider/history`、`/rider/account`、`/rider/prepare`。旧登录、箱体、任务详情路径保留。业务深链刷新后按原内存 JWT 规则重新登录，再返回同角色保护页面；只保存地址意图，不保存 token，拒绝外部跳转或角色不匹配的返回目标。

## 2. 原型视觉对照与必要差异

修改前实际运行三个原型/入口，捕获 9 张原型主页和 9 张当前正式主页。补捕未知状态、骑手准备与访客入口 12 张原型。全部为实际 Chromium 渲染，不使用生成图；正式页基线与三尺寸矩阵使用明确的受控 API 响应，不能称为真实数据库证据。

| 页面 | 已还原的 P0 | 原型与实际数据造成的合理差异 | 人工核对结论 |
|---|---|---|---|
| 企业桌面/平板 | 深蓝 Sidebar、Topbar、统计/分区、地图大主区和任务侧区；任务选择与资产入口 | 无实际 GPS，不绘制假资产点、路线或城市；不展示虚构在线数/告警/KPI；字号放大至可读范围，平板主区上下重排 | 主构图与角色方向保留，P0 通过 |
| 骑手手机 | 当前运输主块内含身份/环境/读数/CTA，四项底栏，三步指示 | 后端只提供 UNKNOWN，使用不确定状态；接口不提供节点在线，不显示假在线；全日期替代静态 14:32，保留真实用户与刷新 | 主要入口在首屏且不被底栏遮挡，P0 通过 |
| 骑手桌面/平板 | 主运输与简洁箱体的非对称双栏，历史、我的与准备清晰分层 | 无原型示例身份、静态数据或评审工具；多个任务分别请求本任务监测 | 布局与对应任务关联通过 |
| 访客手机 | 验证表单；身份→环境→二级记录→运输进度，无底栏 | 显示真实任务编号/日期、UNKNOWN；原型“异常记录”明确称设备事件，避免误称已确认告警；不展示公开凭据 | 信息顺序、只读入口与权限界限通过 |
| 访客桌面/平板 | 入口介绍/表单两栏；验证后环境主区＋进度侧区 | 采样不完整时不补造完整全程；真实仪表值保留服务端精度，可能比原型小数位多 | 结构和阅读层次通过 |

三尺寸为 390×844、768×1024、1440×900。人工打开核对了原型、改造前、改造后和同视口三列对照，重点检查导航、首屏结论、主操作位置、分区顺序和字级；并查看真实联调骑手、访客及企业完成页。没有使用像素相似率或将自动无溢出当作视觉验收。

P1 差异包括较大可读字体、实际时间字符串、少量图标与按钮尺寸；原型顶端评审工具、模拟身份和宣传文字不进入正式产品。全页截图中固定底栏位于截图起始视口底部；页面末尾已预留空间，可滚动访问内容。没有覆盖实体手机、系统级读屏认证或未列出的屏幕尺寸。
