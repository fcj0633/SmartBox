# 联调验收场景

## P1 无板闭环

按 ITER-001：实际 Broker + MySQL + 后端 + Vue + 两模拟节点。检查身份、同箱体快照、精确事件确认、去重、权限和命令结果。模拟输入可重放，原始消息和数据库记录对应。

## P2 实际双板

替换模拟输入为真实ENV/POSE，其他链路保持契约。验证量程/单位、采样、时间质量和实际输出。必须有固件身份与校验值，避免取错角色。

## P3/P4 故障

云端门融合窗口、未校时、迟到、历史补传、部分布防、Broker/服务/数据库故障和重启恢复；事务失败不确认，outbox故障可恢复。

每次执行形成独立报告，明确环境与阶段。不得以P1结果宣称真实传感器、Flash或24h通过。
