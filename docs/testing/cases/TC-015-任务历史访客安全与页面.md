## DEMO 最小测试范围

1. 一个真实或模拟运输任务，从骑手端开始/结束，企业端可以看到任务，普通用户凭编号和验证码查看同一任务。
2. 错误验证码拒绝；用户修改 task_id 或请求时间范围不能查阅其他任务/整箱数据。
3. 在有效设备时间范围内提供本任务环境历史；无可信记录时展示“数据不足”，不误显示为正常。
4. 页面完成最少一次手机及桌面尺寸检查，确保导航、结束操作和访客验证能正常使用。

**可推迟：** 复杂迟到补传历史重归属、主动令牌撤销和重签发、访客 WS、长周期性能/稳定性、完整三视口 × 全状态矩阵。对公网公开访问时必须另外补安全与限流，不得将本 DEMO 测试称为生产安全验收。

## 通过标准

正式 Spring Boot + MySQL + Vue 主业务可演示，任务级只读权限存在，错误验证码和跨任务查询不能越权；缺失数据与 MOCK 明确标注。

## 实际结果

2026-11-23：用户确认在隔离smartbox_test、真实本地Broker和独立模拟节点完成三端浏览器主流程。6项TransportViewIT覆盖可信时间边界、单任务授权、码/会话替换、角色隔离、时限及限流；390×844与1440×900可操作。实板、访客WS、多人会话、可靠补传及生产安全未覆盖，完整候选不自动验收。详细记录见[报告](../reports/TASK-013-三端运输业务联调报告.md)。
