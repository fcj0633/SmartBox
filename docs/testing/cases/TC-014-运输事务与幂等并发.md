## DEMO 最小测试范围

1. 准备任务并填写物品 → 开始 ACTIVE → 结束 COMPLETED → 旧任务在历史中保留。
2. 同一箱体连续/近似同时发起两次开始，第二次应得到清晰冲突或已完成结果，数据库不能出现两条 ACTIVE。
3. 无使用权骑手提交开始请求必须被拒绝；设备离线时开始不能错误显示成功。
4. 结束后可以用同一箱体发起另一新运输，之前的结束时间和物品不被覆盖。

**可推迟：** 20 并发压力测试、完整幂等请求指纹框架、灾难恢复矩阵、紧急接管和复杂多实例一致性测试。这些**不计为已通过**。

## 通过标准

使用真实 MySQL/HTTP 验证主链路、同箱排他和一个无权负例，不以 Vue Mock 代替后端事务。
