## DEMO 最小测试范围

1. 初始化一个企业管理员、一名骑手和一台企业箱体，企业分配后，骑手的“我的箱体”出现对应资产。
2. 收回箱体后，骑手不再获得新的使用资格；无权限账号尝试查看/分配另一企业箱体必须拒绝。
3. 同一个箱体不能同时存在两条当前分配（数据库约束或一次重复分配检查即可）。

**可推迟：** 企业成员复杂层级、多人高并发抢占、紧急接管、所有权转让、全量审计报表和跨企业压力测试。这些**不计为已通过**。

## 通过标准

真实 MySQL 与 HTTP 主流程可重复，两个关键权限边界（企业归属和骑手当前分配）由服务端保证；能在界面展示分配变化。
