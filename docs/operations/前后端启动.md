# 前后端启动

本仓库只保留前后端运行所需内容；不包含 `tools/`、`tests/` 或硬件操作脚本。

## 1. 环境

- JDK 21、Maven
- MySQL 8
- Node.js 22+、npm

## 2. 数据库

创建数据库和账号（示例名称，自行替换密码）：

```sql
CREATE DATABASE smartbox CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
CREATE USER 'smartbox_app'@'localhost' IDENTIFIED BY 'replace-me';
GRANT ALL PRIVILEGES ON smartbox.* TO 'smartbox_app'@'localhost';
FLUSH PRIVILEGES;
```

后端启动时由 Flyway 执行迁移；不要自动删库或覆盖已有数据。

## 3. 后端

PowerShell 示例：

```powershell
$env:SPRING_PROFILES_ACTIVE = "dev"
$env:SMARTBOX_DB_URL = "jdbc:mysql://127.0.0.1:3306/smartbox?connectionTimeZone=UTC&characterEncoding=UTF-8"
$env:SMARTBOX_DB_USER = "smartbox_app"
$env:SMARTBOX_DB_PASSWORD = "replace-me"
$env:SMARTBOX_MIGRATION_URL = $env:SMARTBOX_DB_URL
$env:SMARTBOX_MIGRATION_USER = $env:SMARTBOX_DB_USER
$env:SMARTBOX_MIGRATION_PASSWORD = $env:SMARTBOX_DB_PASSWORD
# 32 字节 base64，示例仅供本地演示；生成后替换
$env:SMARTBOX_JWT_SECRET_BASE64 = "REPLACE_WITH_BASE64_32_BYTES"
$env:SMARTBOX_MQTT_ENABLED = "false"
$env:SMARTBOX_BOOTSTRAP_FILE = (Resolve-Path "deploy/demo/bootstrap.example.json").Path
$env:SMARTBOX_ASSET_SEED_FILE = (Resolve-Path "deploy/demo/enterprise-v2.seed.example.json").Path
mvn -f backend/pom.xml spring-boot:run "-Dspring-boot.run.arguments=--server.port=8080 --smartbox.bootstrap=true --smartbox.assets.bootstrap=true --smartbox.demo.fleet=true"
```

后端启动后可检查：

```powershell
Invoke-WebRequest http://127.0.0.1:8080/actuator/health
```

`deploy/demo/bootstrap.example.json` 和 `enterprise-v2.seed.example.json` 是演示账号/数据示例；生产/共享环境必须替换密码和 JWT 密钥。

## 4. 前端

```powershell
cd frontend
npm ci
$env:SMARTBOX_API_TARGET = "http://127.0.0.1:8080"
npm run dev
```

打开 `http://127.0.0.1:5173`。演示账号见 bootstrap 示例（默认 `admin/admin`，仅本地演示）。

前端登录预填可复制示例：

```powershell
Copy-Item frontend/.env.example frontend/.env.development.local
```

## 5. 边界

- 本仓库不包含自动化测试、Python 工具、MQTT 操作脚本、硬件构建/烧录、模拟器或协议夹具。
- `firmware/` 仅作为源码参考，不能按本仓库完成板端构建。
- 后端 MQTT 默认关闭；演示数据由 `DemoFleetService` 生成。
- 真实设备、云端 Broker、生产部署和完整协议验证不在本仓库范围。
