# 真实开发板接入

## 结论

默认配置已经指向固定远程 Broker，后端启动后会自动尝试连接：

```text
浏览器 -> 前端 -> 后端 -> 远程 MQTT TLS Broker -> 开发板
```

固定 Broker：

```text
z789ffe0.ala.cn-hangzhou.emqxsl.cn
TLS 8883
```

不使用本地 Broker，也没有 `local`/1883 回退。

**板子 Wi-Fi 已联网 ≠ 箱体在线。** 箱体在线要求：

- 板端连接 Broker；
- MQTT 账号/ACL 正确；
- 节点 ID 与数据库一致；
- 上报到正确 Topic；
- 后端已订阅对应 REAL 节点。

## 默认行为

后端读取：

```text
deploy/demo/mqtt.cloud.json
```

固定配置包含：

```text
URL      ssl://z789ffe0.ala.cn-hangzhou.emqxsl.cn:8883
USER     smartbox_backend
PASSWORD 已随仓库提交的演示密码
CA       deploy/demo/emqxsl-ca.crt
```

启动后自动连接，不需要手工设置：

```text
SMARTBOX_MQTT_URL
SMARTBOX_MQTT_USER
SMARTBOX_MQTT_PASSWORD
SMARTBOX_MQTT_CA_FILE
```

除非需要覆盖演示配置，否则不要设置这些环境变量。

## bootstrap 与 Web 启动

首次初始化时关闭 MQTT：

```powershell
mvn -B -f backend/pom.xml spring-boot:run "-Dspring-boot.run.arguments=--smartbox.bootstrap=true --smartbox.assets.bootstrap=true --SMARTBOX_MQTT_ENABLED=false"
```

Web 后端默认自动连接，不需要再传 `SMARTBOX_MQTT_ENABLED=true`：

```powershell
mvn -B -f backend/pom.xml spring-boot:run "-Dspring-boot.run.arguments=--server.port=8080 --smartbox.demo.fleet=true"
```

若需要临时关闭：

```powershell
mvn -B -f backend/pom.xml spring-boot:run "-Dspring-boot.run.arguments=--server.port=8080 --smartbox.demo.fleet=true --SMARTBOX_MQTT_ENABLED=false"
```

## 节点与主题

节点 ID 必须与数据库一致：

```text
BOX-0001-ENV
BOX-0001-POSE
```

每个节点使用自己的 MQTT 账号和 ACL，主题：

```text
box/BOX-0001/BOX-0001-ENV/property
box/BOX-0001/BOX-0001-ENV/heartbeat
box/BOX-0001/BOX-0001-ENV/event
box/BOX-0001/BOX-0001-ENV/command_ack
box/BOX-0001/BOX-0001-ENV/availability

box/BOX-0001/BOX-0001-POSE/property
box/BOX-0001/BOX-0001-POSE/heartbeat
box/BOX-0001/BOX-0001-POSE/event
box/BOX-0001/BOX-0001-POSE/command_ack
box/BOX-0001/BOX-0001-POSE/availability
```

后端账号 `smartbox_backend` 只读取这些上行主题，并写入对应 `cmd`/`event_ack` 下行主题。

## SNTP 与 client ID

- 板端必须完成 SNTP 或明确时间质量；时间无效会导致离线/采样质量异常；
- MQTT client ID 默认生成 `smartbox_backend-<随机后缀>`，避免多个后端同时启动时互相踢线；需要固定时用 `SMARTBOX_MQTT_CLIENT_ID` 覆盖；
- 同一 client ID 不能同时被两个后端使用，否则会互相踢下线。

## 连接检查

```powershell
Invoke-WebRequest http://127.0.0.1:8080/actuator/health
```

- health 200：后端 Broker 链路已建立；
- health 503：Broker/CA/账号/网络问题；
- `BOX-0001` 仍离线：检查板端节点 ID、Topic、ACL、SNTP 和 client ID。

后端连接成功日志会包含 REAL 节点数量，不打印密码/CA 内容。

## 边界

- main 不提供 Broker 创建、SDK、烧录工具或硬件联调脚本；
- `firmware/` 源码仅作参考；
- 演示密码/配置公开在 Git 中，不能用于生产；
- 真实设备不可用时必须写“未验证”，不能把数据库中的 `BOX-0001` 身份当作在线证据。
