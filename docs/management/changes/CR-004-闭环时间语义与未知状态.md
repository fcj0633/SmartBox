# CR-004 闭环时间语义与未知状态

状态：用户已确认，本任务软件切片已实施并验证。日期：2026-11-07。来源：用户批准TASK-005实施计划前的选项答复及随后完整实施指令。执行者Codex；用户独立验收。不追改CR-001～003、原始输入或TASK-001冻结文件。

## 原因与范围

接入、查询和控制开始运行后，Q-01/Q-02/Q-09/Q-11中的部分空白必须有明确口径；冻结告警布尔值无法表示算法尚未接入，整包时间也无法证明位置重新采样。本变更只落实用户明确选择，沿用现有六模块和编号，不增加业务领域。

## 已批准规则

1. 定位独立15秒新鲜度，环境和姿态5秒不变。位置新增兼容的loc.observation，含sample_seq及Time字段；同一次采样重复上报保持标记。序号按node/boot递增，坐标相同也可为新采样。旧消息可保存；缺标记时位置新鲜度UNKNOWN、stale=true。FIXED模拟位置每10秒更新，其余模式每秒，遥测仍每秒。
2. 布撤防操作10秒截止，其他命令按原15秒有效期。操作终态固定，迟到回执另外保存；只有匹配当前代次及最新相关请求/修订的事实才更新实际状态，不自动撤销。全部成功为SUCCEEDED；截止后有成功但未全部成功为PARTIAL；无成功且仍未完成为EXPIRED；全部明确失败为FAILED。
3. profile成功回执必须表示节点已采用，后端才更新采用配置。切换重置未触发去抖计数，已有告警保留，按新规则判断恢复。本期模拟器不实现环境判断器，此规则约束后续TASK-008，不将模拟保存参数当算法验收。
4. 历史事件与轨迹统一按received_at和唯一ID检索排序。设备UTC、质量和接收时间分别保留；UNSYNCED不伪造UTC，不用于可信实时轨迹或历史双源融合。
5. 有效HTTP/WS告警增加assessment=UNKNOWN/EVALUATED。UNKNOWN时active和level为null；EVALUATED时active为布尔值。TASK-005未接入完整判断器时保持UNKNOWN。采样组增加freshness=FRESH/STALE/UNKNOWN，避免把未知误读为已判正常。
