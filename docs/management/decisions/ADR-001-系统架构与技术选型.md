# ADR-001 系统架构与技术选型

日期：2026-11-06；状态：接受；关联：BL-001、REQ-001～009。

## 背景

两人持续开发，要求完整工程化后端、双板闭环和规范文档。用户明确采用 Spring Boot、MySQL、Vue，不为快速演示替换为轻量临时后端。

## 决策

- 固件：现有 Hi3861 SDK、C、CMSIS-RTOS2；同源双角色，HAL 隔离设备输入。
- 后端：Java 21、Spring Boot、Spring Security、MyBatis、Flyway、MySQL 8；模块化单体，单实例先完成事务与去重。
- 前端：Vue 3、TypeScript、Vite、Vue Router、Pinia、Element Plus。
- 消息：Mosquitto / MQTT 3.1.1；应用端 REST + WebSocket，网页不直连 Broker。
- Windows 承担业务开发与服务；Ubuntu 承担交叉编译。单仓库、受控单向同步，不复制整个 SDK。
- 不设硬件前置门槛；P1 模拟输入仍走真实中间件、服务和数据库。
- 精确依赖版本在 TASK-001 核验并锁定；不把本机已装版本解释为项目依赖版本。

## 后果

可并行开发，后端工程完整；仍需承担真实 MQTT、数据库和板端的集成验证。新增 Redis、微服务、生产平台接入需另写 ADR，不能替代现有需求验收。
