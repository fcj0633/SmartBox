# ADR-004 云端Broker与TLS接入

日期：2026-11-23。状态：已实施，软件及基础双板云端链路验证完成；用户确认Serverless＋服务器TLS验证＋独立账号密码，日常默认云端，本地显式备用。实际进度和未验范围见[报告](../../testing/reports/EMQX云端迁移验证报告.md)。

原实现限定回环TCP/1883和固定LAN IPv4，依赖开发电脑地址。现采用云端DNS/8883；输入来源与Broker位置独立，支持仅服务端运行。网页仍通过本机后端，MySQL仍为业务保存来源，不引入EMQX规则直写数据库或新增HTTP接口。

各端必须验证服务器链、域名和有效期；不提供跳过验证与公网明文降级。mTLS暂不实施，不生成客户端私钥。公开CA与来源可随仓库，真实密码和生成配置只在忽略目录。节点、后端、控制和观察账号隔离，精确Allow加默认Deny。

旧SDK使用mbedTLS预编译库，存在时间检查未编入的约束，板端必须显式检查证书有效期；未经校时不连云端TLS，继续本地采集。构建与真实握手分别验证，资源余量留板端测量。

启动代次仍受数据库和区间账本约束。切换真实板与模拟器时预留互不重叠区间，不删除历史状态。云部署的Serverless配额/消费上限及出站网络是运行依赖，本地测试仍保留。

不改变业务规则、时限、MQTT3.1.1 Topic/QoS/retain及精确业务确认；因此本次记录技术部署决策，不借此更新CR或升级TASK-008/009及完整REQ/TC验收。
