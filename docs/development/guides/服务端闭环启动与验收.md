# 服务端闭环启动与验收

详细设计及范围见[TASK-005](../tasks/TASK-005-接入存储与查询闭环.md)，当前契约见[有效补充](../../../contracts/effective/README.md)，规则依据[CR-004](../../management/changes/CR-004-闭环时间语义与未知状态.md)。本机Windows运行、127.0.0.1监听，不开放防火墙或修改旧Mosquitto服务。

## 本地配置与启动

复用被Git忽略的secrets/backend.local.json（dev/test项目数据库与JWT）和secrets/mqtt.local.json（项目Broker及专用账号）。演示账户在后端配置指向的本地初始化JSON；密码不写入本文或命令行。原MySQL服务需运行，不以root启动应用。

先构建并校验开发库迁移/受控初始化：

```powershell
.venv/Scripts/python tools/backend.py build --profile dev
.venv/Scripts/python tools/backend.py bootstrap --profile dev
```

在四个终端分别运行以下命令；后端加载MQTT配置时仅使用backend账号，不借用测试控制身份：

```powershell
.venv/Scripts/python tools/mqtt.py broker --config secrets/mqtt.local.json
.venv/Scripts/python tools/backend.py run --profile dev --mqtt-config secrets/mqtt.local.json
.venv/Scripts/python tools/mqtt.py node --role ENV --config secrets/mqtt.local.json
.venv/Scripts/python tools/mqtt.py node --role POSE --config secrets/mqtt.local.json
```

端口1883/8080已被占用时检查归属，不结束其他进程。模拟节点单进程单客户端；运行目录、状态和日志自动放忽略目录。节点正常退出保留主机boot代次，但待确认事件内存会丢失；这不是Flash验收。

后端健康地址为http://127.0.0.1:8080/actuator/health，业务前缀/api/v1；HTTP使用Bearer JWT。WS先认证获取/ws-ticket，再带30秒一次性票据连接/ws；Origin必须为允许的前端来源，票据/JWT不可写进日志。电脑端网页已由TASK-006交付，见[网页指南](网页启动与首轮验收.md)。

```powershell
.venv/Scripts/python tools/backend.py test --profile test --allow-test-reset
.venv/Scripts/python tools/live_integration.py --allow-test-reset --run-dir artifacts/task005/新的唯一目录

.venv/Scripts/python tools/effective_contracts.py
.venv/Scripts/python tools/check_contracts.py
python tools/check_docs.py
git diff --check
```

后端集成检查与独立联调不得同时操作smartbox_test。联调入口只使用test配置，并要求显式清理同意，绝不清理smartbox_dev；缺配置或必需工具失败，不跳过。目录必须在artifacts内且尚不存在。

联调使用私有Broker账号和身份状态，不重置日常节点boot。它启动真实Broker、后端和两个节点，验证业务确认、五类控制、查询、CSV、WS及恢复；后端使用实际MySQL，不使用H2。真实90秒静默测试只暂停自身POSE子进程并恢复，不停止共享MySQL或其他进程。

## 迁移与恢复

新增V5节点运行态/位置、V6事件视图、V7命令投递及回执、V8操作顺序、V9新增数据质量约束。V8解决同一毫秒创建请求时的先后比较，不以时间戳碰撞判断旧命令。Flyway校验V1～V4，不修改已应用迁移、不自动clean/repair；失败保留现场，按日志索引定位。

事件提交后才确认；确认丢失由节点重传去重恢复。命令提交后发布，重启重发原请求且不延长有效期；整体超时终态固定，迟到节点事实仍可查询。outbox持久投影与DONE同事务，租约到期回收；未来算法不能创建空DONE工作。

测试故障屏障仅在test进程、SMARTBOX_TEST_FAULTS=true及指定本地标记文件同时满足时生效，没有HTTP入口；日常dev不会启用。联调记录完整清理结果，保留本地配置和项目库，旧服务状态不变。

## 验收边界

未知告警active=null、门UNKNOWN并非系统正常结论。位置MOCK及独立观测质量必须保留；旧消息缺观测标记时位置新鲜度UNKNOWN，不把每秒整包时间当位置采样时间。完整算法、网页、真实采集、GPIO、Flash、掉电和24小时稳定性仍按后续任务验证。实际证据见[TASK-005报告](../../testing/reports/TASK-005-服务端闭环验证报告.md)。

定向发布恢复可用同一联调入口加--scenario dispatch-recovery，仍要求新的artifacts证据目录及显式test清理。完整主联调与定向检查不得同时运行。电脑重启后的接续记录和各项证据时间分别保留，不把桌面重启当设备掉电测试。
