# 后端数据库初始化与启动

当前后端具有接入、可靠事件保存、查询、控制和 WebSocket，使用真实 MySQL。现有结构为 **18 张业务表及 V1～V9**，不将 TASK-003 当时的 13 表/V1～V4 当作当前结构。模块调用见[后端导读](../../../backend/README.md)，首次安装见[完整部署指南](../../delivery/deployment/开发者完整部署指南.md)。

## 1. 初次配置与项目库

准备 Java21、Maven、MySQL8、项目 .venv 与锁定依赖，在仓库根目录执行：

```powershell
.venv/Scripts/python tools/project.py init
.venv/Scripts/python tools/project.py db-init
```

init 生成忽略的随机项目密码、JWT 和演示账号，不覆盖已有秘密；中断记录允许续办同一批凭据。db-init 隐藏输入本机 root 密码，只用于建库和账号，不写入应用或参数。工具不重启共享 MySQL。

| 用途 | 开发 | 集成测试 |
|---|---|---|
| 数据库 | smartbox_dev | smartbox_test |
| 迁移账号 | smartbox_migrator | smartbox_test_migrator |
| 运行账号 | smartbox_app | smartbox_test_app |
| 初始数据 | 四角色、BOX-0001、ENV/POSE | 四角色各两账号、两个箱体 |

默认 TCP127.0.0.1:3306。独立实例可在首次 init 使用 `--mysql-port 13306`。运行/迁移 URL 指向同一本机项目库，账号、库名及测试清理保护不放宽；运行账号只有项目读写权限。

DDL 用绑定端口及 server UUID 的归属记录续办，不保证全事务回滚。未知同名库/账号拒绝，不修改其他项目。已有环境复用配置，不重新 db-init 接管；记录不一致时保留现场核对，不删除记录强行初始化。

## 2. 构建、迁移与受控初始化

```powershell
.venv/Scripts/python tools/backend.py build
.venv/Scripts/python tools/backend.py bootstrap
```

build 解析固定版本、执行单元测试，生成 backend/target/smartbox-backend-0.1.0.jar。bootstrap 以非 Web 模式启动，Flyway 用迁移账号执行/校验结构，运行账号在事务内初始化数据。重跑不重置密码或覆盖授权；冲突回滚初始化事务。

空库首次应执行全部迁移，重复启动只校验。已应用迁移不可修改，不自动 clean/repair，不以 ORM 自动建表代替 Flyway；后续结构变化新增迁移。

secrets/backend.local.json 的 dev/test 对象包含数据库运行/迁移连接、JWT、Origin、回环地址及初始化引用，环境值均为字符串。SMARTBOX_BOOTSTRAP_FILE 支持仓库相对路径，运行时定位；旧绝对路径兼容，移动仓库需显式调整。

演示密码只在对应 secrets/backend-*.bootstrap.local.json 本地查看，不提供注册、换绑或管理 API。Windows AF_UNIX 不可用时，在确认确需后设置本地字符串 SMARTBOX_WINDOWS_TCP_SELECTOR 为 true，不对所有电脑无条件启用。

## 3. 启动

只启动后端基础、不启用 MQTT：

```powershell
.venv/Scripts/python tools/backend.py run
```

整体开发推荐：

```powershell
.venv/Scripts/python tools/project.py start --mode simulator
```

硬件模式用 `--mode hardware`，需先完成[固件配置及烧录](编译烧录与联调流程.md)。不自动预留新区间、烧录或调整防火墙。健康检查为 http://127.0.0.1:8080/actuator/health，网页为 http://127.0.0.1:5173。

精确确认与命令执行依赖 Broker 和节点，健康检查不代表闭环。缺数据库、错误凭据或迁移失败应停止报告，不生成伪造成功数据。

## 4. 测试与收尾

```powershell
.venv/Scripts/python tools/backend.py unit
.venv/Scripts/python tools/backend.py test --profile test --allow-test-reset
```

纯单元不要求数据库。真实集成会清理专属 smartbox_test，必须明确同意；不能用开发库或单元结果替代。系统级复验见[服务端指南](服务端闭环启动与验收.md)及[网页指南](网页启动与首轮验收.md)。

整体管理器用 tools/project.py stop 或 Ctrl+C 收尾；强制中断的记录用 recover-state 核验后归档，不结束未知进程。保留共享 MySQL、项目库和本地配置。完整业务算法及板端可靠性仍需后续验收。
