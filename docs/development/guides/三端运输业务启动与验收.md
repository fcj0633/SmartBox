# 三端运输业务启动与验收

TASK-013在原设备监测工程中新增企业、骑手和访客入口，设备与任务权限分开。前提是按[完整部署指南](../../delivery/deployment/开发者完整部署指南.md)准备Java、MySQL、Node及本地配置，并已完成旧Bootstrap和TASK-011资产种子。沿用已有锁定依赖。

## 1. 构建和受控迁移

仓库根目录执行，应用使用项目账号：

```powershell
.venv/Scripts/python tools/backend.py build
.venv/Scripts/python tools/frontend.py check
.venv/Scripts/python tools/frontend.py build
.venv/Scripts/python tools/assets.py prepare --profile dev
.venv/Scripts/python tools/assets.py bootstrap --profile dev
```

Flyway校验已有V1～V14，新增V15访客表；失败不自动repair/clean，不修改旧迁移。资产初始化不覆盖密码、授权、权属或分配。后端工具加载已有secrets/assets-dev.local.json中的受控骑手集合，企业候选由服务端决定；缺配置按[初始化指南](后端数据库初始化与启动.md)准备。

## 2. 日常运行和三个入口

先按原归属方式停止自己拥有的旧项目实例，再使用新版本；未知8080/5173占用时工具拒绝，不强行结束其他进程。默认云端需已有云端配置：

```powershell
.venv/Scripts/python tools/project.py start --mode server
```

仅服务端模式不启动模拟节点，设备不在线时开始运输返回BOX_OFFLINE是正确行为。硬件模式使用真实板；模拟模式使用对应Broker上的模拟节点，相同节点身份不能同时运行。云端模式不启动本机Mosquitto；本地备用可显式选择--broker-profile local及已准备配置。

- 登录页为http://127.0.0.1:5173/login；登记企业管理员进入/enterprise，骑手进入/rider，未登记操作者和原其他角色保留/boxes。账号凭据只在本地Bootstrap配置查看。
- 企业选择演示骑手并分配，查看本企业任务；ACTIVE任务不能普通收回。
- 骑手选箱创建READY，填写物品后开始；风险未知/活动告警需要用户明确确认，离线不能绕过。个人演示箱无节点，不伪装在线。
- 本人ACTIVE/有效COMPLETED任务可生成验证码；只显示当次，重新生成使旧码和会话失效。
- 访客打开http://127.0.0.1:5173/track，不登录账号，输入编号和验证码查看同一运输。令牌仅内存，刷新/退出需要重新验证。回环地址只适用于本机，手机视口适配不等于已对实体手机或公网开放。

任务页每10秒串行刷新，并提供手动刷新；旧响应不得覆盖新路由。没有可信记录显示数据不足，UNKNOWN不显示正常。结束历史只取本任务设备时间；原箱体页保留旧user_box_access，资产收回不声称吊销所有旧设备权限。

## 3. 隔离软件验收

显式选择smartbox_test并同意测试清理后运行，需要空闲1883、18080、15173；保留既有8080/5173和共享MySQL：

```powershell
.venv/Scripts/python tools/assets.py prepare --profile test
.venv/Scripts/python tools/assets.py test --profile test --allow-test-reset
.venv/Scripts/python tools/transport_view.py --profile test --allow-test-reset --run-dir artifacts/task013/新的证据目录
.venv/Scripts/python tools/check_transport_view_contracts.py
```

统一入口启动专用本地Broker、独立ENV/POSE模拟进程、测试后端和网页。浏览器真实完成企业分配、骑手创建/物品/风险确认/开始、访客错误码及正确验证、MQTT采样与设备事件、结束及三端刷新、旧设备页及访客刷新清除令牌。模拟事件是设备输入样例，不冒充固件算法或真实板结果。

证据目录必须是新的artifacts子目录，缺少工具/端口/配置直接失败。凭据和完整日志继续忽略，浏览器不保存HAR/trace，截图避开验证码显示区域。收尾停止自有进程，不操作云端会话。真实板、可靠补传和生产安全后续单独验收。结果见[报告](../../testing/reports/TASK-013-三端运输业务联调报告.md)。
