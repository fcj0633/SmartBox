端口占用时报告占用事实并退出，不结束其他进程、不悄悄换端口。工具记录自己启动的可执行文件、配置路径和实际PID；停止仅针对可核验归属的自身进程，并验证端口释放。独立Broker与正常运行模式的长期进程、临时集成检查的进程须区分，测试只能清理自己创建的实例。

## 4. 通信、事件与命令规则

### 4.1 连接与容量

MQTT 3.1.1、keepalive=60秒、clean session=true。八类Topic/QoS/retain严格沿用契约：property为QoS0，其余约定消息为QoS1，正常发布retain=false。LWT使用契约最小availability结构，不擅自增加必填完整时间信封。

重连按1/2/4/8/16/30秒上限及0～20%抖动持续重试，成功后复位；重新确认订阅，再发送当前状态和待确认事件。重连不改变boot_id；模拟进程重新启动必须预留新的代次。定时、输出期限和重试使用单调时间，不能因墙钟跳变集中补发过期采样。

JSON payload最多1536字节UTF-8、完整MQTT帧最多2048字节、Topic最多128字节；事件每批最多4条且仍受字节上限约束。接收端检查非法UTF-8、重复JSON键、截断、未知版本和已知字段非法值；未知字段按契约允许忽略，不能全面封闭对象破坏兼容。非法数据不做无限解析重试，能够安全提取请求身份才回错误，否则丢弃计数；不截断后执行。

### 4.2 boot_id、事件与精确确认

boot_id为持久递增uint32。使用项目专属本地状态、独占访问和可靠保存后再连接；同节点/同状态目录并发启动拒绝，不自动重置丢失或损坏的旧状态。首次新身份初始化与已有身份状态丢失明确区分。保存失败或代次耗尽时停止产生声称唯一的新事件并报告，不回绕或随机碰撞替代。

event_seq/property_seq分开从1计数，uint32耗尽前切换代次按契约处理；切换失败停止相应生成，不复用身份。事件键仍为node_id+boot_id+event_seq，不用MQTT包号。

待确认队列默认64条、仅内存；满后覆盖最旧，累计overflow_total和损失区间，通过心跳持续暴露，不依赖向满队列再塞一条事件。进程退出丢失待确认事件/内存计数的限制必须记录；storage使用DEGRADED，不宣称满足MOD-04的Flash、掉电或跨重启持久化要求。主机保存boot_id只服务模拟身份，不证明开发板KV能力。

PUBACK仅证明传输，不清理事件。event_ack必须结构合法、身份与boot匹配、result=stored，且仅清理event_seqs精确集合；不推导“最大值之前全部保存”。重复确认不误删，未知序号不扩大清理范围，错误身份/代次确认拒绝。重传保留事件原始时间/质量/身份/内容，补传标识按契约，不把不同boot_id混批，不因发送时刻改写发生时刻。

测试端可故意不确认、重复确认或只确认部分序号；这只是协议测试。后端真实落库后的业务确认、同键异内容审计和历史处理由TASK-005验证。

### 4.3 命令处理与五类模拟动作

处理链为：有界接收→结构/身份校验→保留消息、参数、能力、时间及缓存检查→模拟动作调度→实际模拟完成回执。无可靠UTC返回time_unsynced，不远程执行；过期、能力部分满足、错误参数或retained命令不改变状态。不同拒绝项组合不在本任务擅定新的业务优先级，使用单故障场景分别验收，组合冲突按现有契约/待决流程处理。

最近至少32个request_id缓存请求内容及结果；同请求重复不再次执行，处理中不重复排队；同号异内容返回conflicting_request。不能只比较cmd而忽略params/operation_id/目标身份。模拟成功只表示模拟动作完成，不等同真实设备执行。

| 命令 | 模拟行为及检查 | 未包含/限制 |
|---|---|---|
| output | 按kind精确检查2/4/16能力位，设置模拟状态，duration_s为1～30，单调期限关闭 | 不调用GPIO，不以日志打印冒充物理动作 |
| gps_mode | 校验FIXED/ROUTE/WALK及seed，采用确定性MOCK输入 | 不新增围栏/路线配置接口，不宣称真实GPS |
| profile | 校验画像与有效恢复区间，保存模拟参数并回显已有实际状态字段 | 不实现告警算法，不决定Q-09切换/计数语义 |
| calibrate | 仅POSE，模拟静置输入与校准流程完成后回执 | 不校准真实传感器，不把成功写成测量精度通过 |
| sentry | 校验64能力位、duration_s、递增revision，按3秒缓冲进入模拟ARMED再完成回执；按已定义期限处理 | 不形成箱体整体结果，不代替真实侵入判断或Q-10重启期限恢复 |

命令有效期初始15秒、箱体操作10秒超时等原语义不改；任务4只验证节点回执，迟到回执与操作结果收敛仍属Q-02及TASK-005/008。sentry_revision的本地模拟保存不能宣传为板端掉电一致性；恢复后的哨兵/期限未确认能力不标为成功。

box_state只完成结构、身份和接收验证，不新增TTL、不自行启用Q-08尚未确认的“未过期”抑制行为。历史门结论和离线抑制不借模拟器形成新规则。

测试retained命令必须先在专用Broker保存消息，再让节点订阅收到retain=true的实际保留投递；在线订阅者收到的普通即时转发不能冒充该测试。测试结束清理自己注入的保留消息；正常消息始终retain=false。
