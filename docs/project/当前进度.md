# 当前进度

## 当前可用

- 企业端运营总览、物流箱资产、运输任务、MOCK 地图、告警中心。
- 模拟箱体创建/编辑、场景切换、启停。
- 箱体详情八分区：环境、姿态、定位、告警、节点、控制历史、日志。
- 企业控制中心命令提交与回执展示（真实设备 ACK 未验收）。

## 当前边界

- 旧骑手、访客、旧设备工作台及其 API 已从 main 移除；完整历史代码保留在 `full-engineering` 工作树。

- 本仓库只保留前后端与演示数据；没有 tools、tests、硬件构建/烧录。
- 后端 MQTT 默认关闭；本地演示使用 `DemoFleetService` 和演示种子。
- 真实设备、生产安全、长期可靠性和完整协议验证不在本仓库范围。
- 告警人工处置、CSV、轨迹回放未实现。

## 下一阶段
