# 本地产物与证据目录

这里存放开发和验收时生成的固件、日志、截图、清单及恢复资料。**除本README外默认Git忽略**，克隆仓库不会得到这些文件，也不会带来本机凭据；受控报告保存在docs，按索引关联本地证据。

| 内容 | 放置与使用约定 |
|---|---|
| 固件构建 | 按运行和ENV/POSE角色独立归档，保留源码快照/差异、工具版本、日志、产物SHA256及manifest |
| SDK备份/恢复 | 与构建运行关联，含原入口/输出/厂商状态及恢复清单；未确认恢复前不可删除 |
| 软件联调/浏览器 | 新的唯一运行目录保存脱敏摘要、状态和必要截图，不能和旧运行混淆 |
| 检查日志 | 记录实际命令、退出结果和适用范围，不把工具通过当作完整业务验收 |
| 本地依赖/缓存 | 仅供本机使用，不是项目源码，也不应被打包为普通证据分享 |

命名建议`artifacts/{阶段或工具}/{唯一运行编号}/`，具体工具可能使用自己的默认子目录。保存角色、来源与校验值后再复制镜像到便于烧录的位置；不能把同一bin改名当两个角色。产物构建早于提交时，用源码快照定位，不编造镜像内提交号。

密码、配置和持久身份状态使用各工具规定的忽略位置，不因为artifacts被忽略就随意复制秘密或删除启动区间账本。删除原始证据会使受控报告索引不可复核；失败/恢复资料尤其应先核对再处理，目录不是可无条件清空的缓存。

跨机器复核需另行传递脱敏证据包及相对路径/SHA256清单，不能只提供本机绝对路径。如何记录、分享及判定见[证据规则](../docs/testing/evidence/README.md)，测试层次见[测试导读](../tests/README.md)。本README说明存放规则，不保证任何示例目录已经存在。
